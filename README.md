# Desert Media

Hi there 👋

This is a repository containing simple code files for the Desert Media class.

Each file is a small, self-contained CircuitPython program that runs on a
single NeoPixel — drop one onto the CIRCUITPY drive as `code.py` and it runs.

## Files

### [Times of Day](timesofday.py)

The colours of the sky across one day, on a single NeoPixel. It starts in
darkness, warms through first light into golden morning, climbs to flat white
at noon, then leans back down through gold and red into night. Colour and
brightness both change, and one full day takes about 30 seconds before it
loops.

Set `ROOM_BRIGHTNESS` at the top to suit the room.
